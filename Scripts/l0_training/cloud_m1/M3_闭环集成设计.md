# M3 闭环集成设计 · L0 代理模型接入方案生成阶段

> 状态：设计稿 + 本地可运行骨架（`ab_eval.py` 已验证）
> 依赖决策：见方案 §10（云载体 / 触发节奏）；实际接线在 **MotorAI 方案生成阶段仓库**与推理端 `lib/surrogate-engine.mjs`，本文件只定义接口与判据。

---

## 1. 闭环数据流（数据飞轮）

```
方案生成阶段 L0(surrogate) 排序 TopN
      │  （surrogate 默认开启 + 置信度门控 0.4 自动降级公式）
      ▼
L1(RMxprt) 对 TopN 精算 → 真解 l1_eff 回流 designs.db.l0_residuals
      │
      ▼
云端重训（M1 流水线）→ 模型更准（M2 注册表/回滚）
      │
      ▼
下一轮 L0 更好 → 飞轮加速
```

反例保护：`V08` 轭饱和、`V16` 极数-转速同步等物理不可行，推理端段外 `range-miss` 自动降级公式通道，绝不被硬给数。

## 2. surrogate 默认开启开关

推理端当前默认 `l0Mode='formula'`（安全）。M3 上线动作：

- 配置项 `l0Mode` 默认改 `'surrogate'`；保留 `formula` 作为降级；
- `gate.threshold=0.4`（已在 v3.1.0 schema 内置）：置信度 < 0.4 的预测自动回退公式通道，零回归风险；
- `experimental=true` 阶段先在内部/小流量租户灰度（见 §4），A/B 达标再全量。

## 3. A/B 评估骨架（已可运行）

`ab_eval.py` 用 RMxprt 真解（l1_eff）作金标，在「同规格候选集」内比较排序器：
Top1 命中率 / Top3 命中率 / 组内 Spearman。

**本地实测（6029 行，46 个组内≥3 候选集）：**

| 排序器 | Top1 | Top3 | Spearman |
|---|---|---|---|
| formula(l0) | 0.174 | 0.261 | 0.001 |
| surrogate v3.1.0 | 0.304 | 0.391 | 0.685 |

surrogate 相对 formula **Top1/Top3 各 +13.0pt**，Spearman 从近乎无关升到 0.685——**这是 surrogate 默认开启的核心量化依据**。

> 判据建议：上线门槛 `Top1_surrogate − Top1_formula ≥ +5pt` 且 `Spearman_surrogate ≥ 0.5`；本实测已大幅越过。

## 4. 灰度发布 + 回滚（复用 M2）

- 新模型先 `experimental=true` 小流量 → `model_registry.py` 登记（`register`），`current` 指针切到新版本仅经 `rollback --to`；
- 门禁失败或线上指标退化 → `model_registry.py rollback --to <上一版>` + `export --to <部署槽>` 受控切回，**绝不自动覆盖线上插件模型**；
- 灰度期并行跑 `ab_eval.py` 持续监控排序质量。
