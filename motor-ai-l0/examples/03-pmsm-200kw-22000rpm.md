# 算例 3 · 200kW / 22000rpm / 380V 高速 PMSM（**能力边界反例**）

> ⚠️ 这个算例**故意展示插件做不好的工况**。我们把它完整公开，是为了让使用者一眼看清 L0 的适用边界 ——
> 而不是装上一跑、拿到一堆看似漂亮的效率数字就去报价。

## 1. 输入（Spec）

| 项目 | 值 |
|---|---|
| 功率 | 200 kW |
| 转速 | 22000 rpm |
| 电压 | 380 V |
| 机种 | pmsm（永磁同步，高速） |
| 候选规模 | 120 |

## 3. 逐项解读

| 现象 | 说明 |
|---|---|
| **轭磁密 5.28 T** | 物理上不可能（硅钢 1.8–2.0 T 即深度饱和）。根因是本版 L0 的轭部磁路模型未覆盖 22000rpm / 2 极高速工况的极短轭部路径，属**模型外推失真**，不是设计结果 |
| **温升 338–380 K** | 远超 F 级限值 105 K。高速风摩耗与高频铁损的估算模型在本版未标定 |
| **`recommended = null`、`feasible_count = 0`** | ✅ **这是正确的行为**：V08 轭饱和门控识别到 `yoke_sat = true`，拒绝输出任何"看起来可行"的方案。宁可交白卷，也不给假答案 |
| 效率 95.33–95.42% | 在模型失真前提下**不可用**，请勿采信 |

## 4. 结论与建议用法

| 工况 | L0 是否适用 |
|---|---|
| 中低速异步机（≤3000rpm，150–1085mm 机座） | ✅ 适用，见算例 1 / 2 |
| 常规 PMSM（≤6000rpm） | ⚠️ 排序可用，绝对值需 L1 复核 |
| **高速 PMSM（>10000rpm）** | ❌ **不适用**，请直接进入 L1（RMxprt）/ L2（Motor-CAD） |

插件的 `level` 配置会强制这一点：`l0Mode: 'auto'` 下无效方案不会进入 TopN；若你把 `level` 设为 `l1`/`l2`，插件会**立即抛错**而不是静默给出 L0 结果 —— 这是刻意设计的快速失败。

## 5. 复现命令

```bash
node -e "
import('./tools/l0/param-matrix.mjs').then(async (M) => {
  const E = await import('./tools/l0/l0-estimate.mjs')
  const cfg = { l0Mode: 'auto', level: 'l0' }
  const rows = M.buildParamMatrix({ power_kw: 200, speed_rpm: 22000, voltage_v: 380, motor_type: 'pmsm', count: 120 }, cfg).matrix
  const r = E.runL0Estimate({ params_list: rows, top_n: 5, sort_by: 'efficiency' }, cfg)
  console.log('feasible =', r.feasible_count, '| recommended =', JSON.stringify(r.recommended))
})
"
```
